# Bybit native spot-perpetual funding-only screen

Specified before reading Bybit's current funding-history API for this screen. This is a funding-only feasibility bound for BTCUSDT, ETHUSDT and SOLUSDT linear perpetuals, not a realized native-spread trade, executable return or untouched model holdout.

- Use exactly three adjacent 30-day UTC windows: 2026-06-27 to 2026-07-27, 2026-07-27 to 2026-08-26, and 2026-08-26 to 2026-09-25, each start inclusive and end exclusive. To avoid assuming a fill at the settlement instant, count only funding timestamps **strictly inside** each window. Fetch all first-party historical funding records through `/v5/market/funding/history` with explicit time bounds and pagination; retain every raw API response and error. Query official linear instrument metadata for each symbol and record its current funding interval. Do not replace missing records, days or symbols.
- Model buying spot and selling the matching perpetual through Bybit's native `FundingRateArb` combo at each window start, then closing at its end. For a fixed unit of reference notional, sum the signed settled funding rates as short-side receipts. This normalizes changing mark-price notional and therefore is only an approximation. Negative funding is a payment. Do not use the current displayed next funding rate as a historical substitute.
- Subtract 0.155% of reference spot notional per 30-day round trip as **conditional** published VIP 0 native-combo entry-plus-exit trading fees, 0.25% as adverse combined entry/exit spread crossing and execution, and 1% annual capital charge on illustrative `2.025` units of reserved capital per unit spot notional. These amounts are fixed before reading data. They omit actual account rates, borrowing, liquidation, changing mark notional, native spread entry/exit prices and basis P&L.
- Report each 30-day net funding-less-configured-cost value and its return on reserved capital. Flag a window incomplete when adjacent historical funding timestamps inside it differ by more than eight hours; also require pagination to cover the requested start and end. A symbol passes only a **funding-only research gate** if all three 30-day values are positive, no data window is incomplete, and the mean monthly reserved-capital return annualizes to at least 4%. Passing would justify a separate native-book and historical spot/perpetual basis study; it is not proof of robust after-cost profit. Any missing interval or incomplete API set is unassessable, not zero funding.
